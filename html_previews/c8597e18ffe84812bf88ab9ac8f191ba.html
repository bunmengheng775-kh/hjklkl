លំហាត់រូបវិទ្យា៖ ល្បឿនមធ្យម និងវ៉ិចទ័រល្បឿនខណៈ

លំហាត់ទី១៖ ចលនាត្រង់ស្មើ និងការឈប់សម្រាក

បម្រាប់៖ ក្រាបខាងក្រោមជាក្រាបចម្ងាយចរ-ពេល នៃរថយន្តមួយដោយមានចំណុច A(0, 0), B(4, 20), និង C(6, 20)។

សំណួរ៖

១. ចូរគណនាល្បឿនមធ្យមរបស់រថយន្ត ក្នុងចន្លោះពេលពី t = 0s ទៅ t = 6s។
២. ចូរគណនាតម្លៃល្បឿនខណៈ និងកំណត់វ៉ិចទ័រល្បឿនខណៈ នៅពេល t = 2s និងនៅពេល t = 5s។

ដំណោះស្រាយ៖
១. ល្បឿនមធ្យម ពី 0s ទៅ 6s៖
Vm = Δx / Δt = (20 - 0) / (6 - 0) = 20 / 6 ≈ 3.33 m/s

២. វ៉ិចទ័រល្បឿនខណៈ៖
- នៅ t = 2s (លើបន្ទាត់ AB): V1 = (20 - 0) / (4 - 0) = 5 m/s (ទិសដៅស្របនឹងចលនា)
- នៅ t = 5s (លើបន្ទាត់ BC): V2 = (20 - 20) / (6 - 4) = 0 m/s (រថយន្តឈប់ស្ងៀម)

លំហាត់ទី២៖ ចលនាមានទិសដៅបញ្រ្ចាសគ្នា

បម្រាប់៖ សិស្សម្នាក់ជិះកង់មានក្រាបទីតាំង-ពេល កំណត់ដោយចំណុច P(0, 10), Q(2, 40), និង R(5, 10)។

សំណួរ៖

១. ចូរគណនាល្បឿនមធ្យម (Average Speed) និងវ៉ិចទ័រល្បឿនមធ្យម (Average Velocity) ក្នុងចន្លោះពេលពី t = 0s ទៅ t = 5s។
២. ចូរគណនាតម្លៃវ៉ិចទ័រល្បឿនខណៈ នៅពេល t = 1s និង t = 4s។

ដំណោះស្រាយ៖
១. ល្បឿនមធ្យម និងវ៉ិចទ័រល្បឿនមធ្យម (0s → 5s):
- ល្បឿនមធ្យម (គិតលើចម្ងាយ d): ជិះទៅមុខបាន 30m + ត្រលប់ក្រោយ 30m = 60m។ V = 60 / 5 = 12 m/s
- វ៉ិចទ័រល្បឿនមធ្យម (គិតលើបម្លាស់ទី Δx): Δx = 10m - 10m = 0m។ Vavg = 0 / 5 = 0 m/s

២. វ៉ិចទ័រល្បឿនខណៈ៖
- នៅ t = 1s (លើ PQ): V1 = (40 - 10) / (2 - 0) = 15 m/s (ទិសដៅទៅមុខ)
- នៅ t = 4s (លើ QR): V2 = (10 - 40) / (5 - 2) = -10 m/s (ទិសដៅផ្ទុយ ឬជិះត្រលប់ក្រោយ)

លំហាត់ទី៣៖ ក្រាបរាងខ្សែកោង និងបន្ទាត់ប៉ះ

បម្រាប់៖ វត្ថុមួយមានចលនាស្ទុះស្មើ (ក្រាបរាងប៉ារ៉ាបូល)។ បន្ទាត់ប៉ះក្រាបត្រង់ t = 3s កាត់តាមចំណុច M(1, -6) និង N(3, 18)។

សំណួរ៖

១. តើល្បឿនមធ្យមរបស់វត្ថុពី t = 0s ទៅ t = 4s មានតម្លៃប៉ុន្មាន?
២. ដោយប្រើប្រាស់បន្ទាត់ប៉ះក្រាប ចូរគណនាតម្លៃនៃវ៉ិចទ័រល្បឿនខណៈនៅពេល t = 3s។

ដំណោះស្រាយ៖
១. ល្បឿនមធ្យម ពី 0s ទៅ 4s៖
Vm = (32 - 0) / (4 - 0) = 8 m/s

២. ល្បឿនខណៈនៅពេល t = 3s៖
វ៉ិចទ័រល្បឿនខណៈស្មើនឹងមេគុណប្រាប់ទិសនៃបន្ទាត់ប៉ះត្រង់ចំណុចនោះ។
V = (xN - xM) / (tN - tM)
V = (18 - (-6)) / (3 - 1) = 24 / 2 = 12 m/s
